## 功能特性

面试侠把分散的备考工具收敛成一个顺手的工作台，覆盖从刷题、模拟、复盘到投递追踪的全链路。

### 1. 文字 / 语音模拟面试
- 按岗位 JD **智能出题**，贴合目标公司与职级。
- **实时多轮对话**模拟真实面试追问，支持文字与**语音面试**两种模式，还原考场节奏。
- 每道题给出**评分与改进建议**，练习结束生成结构化报告，指出薄弱项。

### 2. AI 简历精修
- 上传简历**一键诊断**，定位表达、结构与匹配度问题。
- AI 按目标岗位**重写与润色**，突出项目亮点与量化成果。
- 自动生成**改后成稿**，可直接导出使用。内置多套简历模板（经典 / 现代 / 极简 / 优雅 / 时间线 / 对比）。

### 3. 智能题库与学习模式
- **数千道预置高频题**，覆盖主流岗位与知识点。
- 按**标签 / 难度**灵活筛选，记录每道题的掌握度与「我的答案」。
- 学习模式支持**上一题 / 下一题**循序渐进（键盘 ← → 翻题），参考答案默认折叠，访问统计实时更新。
- 支持 **PDF 导入**：规则切分优先，低覆盖率自动降级 LLM 切分，经审核后发布，杜绝内容注入。

### 4. 知识库面试
- 把资料、笔记、论文**入库**成为专属知识库。
- AI **自动生成题库**并基于知识库问答，打造只属于你的备考素材，告别千篇一律的通用题。

### 5. 真实录音复盘
- 上传面试录音，**自动转写**（火山豆包 ASR，说话人分离）。
- 自动**定位表达与内容薄弱点**，给出可执行的改进项。
- 支持**二次针对性面试**，针对短板再练一轮，越练越稳。

### 6. 求职追踪看板
- 统一管理**投递进展与 Offer**，时间线清晰。
- 薪资、轮次、节点**一目了然**，不再错过关键时机。

### 7. 面经广场
- 来自**真实候选人**的面经分享，覆盖大厂与垂类岗位。
- 避坑不踩雷，备考有参照。

### 8. 会员与点数体系
- 灵活的**会员权益 + 点数包**，按需使用 AI 能力。
- 随时升级、随时停用，**成本自己掌控**，不为闲置付费。

## 技术栈与设计

- **零运行时依赖**：不引入任何框架 / CDN / 构建步骤，打开 `index.html` 即可运行。
- **纯静态**：HTML 语义化结构 + 原生 CSS 变量主题系统 + 原生 JS（无打包）。
- **双主题**：内置浅色 / 深色主题，自动跟随系统偏好，并记忆用户选择。
- **响应式**：移动端自动收起导航为汉堡菜单，栅格自适应 4 → 2 → 1 列。
- **滚动渐显**：基于 `IntersectionObserver` 的入场动画，尊重 `prefers-reduced-motion`。
- **内联图标**：使用 SVG `<symbol>` 精灵，避免外部图标库请求。
- **设计令牌**：苹果蓝 `#0071E3` + 品牌橙 `#F97316` + 暖灰 slate 中性色，统一可控。

## 部署到 GitHub Pages

仓库已内置 GitHub Pages 自动部署工作流（推送 `main` 分支即发布）。

1. 在 GitHub 新建一个公开仓库（例如 `mianshixia-landing`）。
2. 把本目录的内容推送上去：

   ```bash
   git init
   git add .
   git commit -m "feat: 面试侠静态落地页"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

   > 已安装 GitHub CLI 时更简洁：
   > ```bash
   > gh repo create mianshixia-landing --public --source=. --push --main=main
   > ```

3. 在仓库 **Settings → Pages** 中，将 Build and deployment 的 Source 设为 **GitHub Actions**。
4. 等待 Actions 跑完，站点即发布在 `https://<用户名>.github.io/<仓库名>/`。

也可一键部署到 Vercel / Netlify：直接导入本仓库，无需任何构建命令与输出目录配置。

## 自定义指南

- **改跳转地址**：编辑 `main.js` 顶部的 `SITE_URL`，所有「免费开始 / 登录」按钮会指向该地址；也可把功能卡片的 `feature__enter` 改成真实路由。
- **改文案与功能**：功能卡片数据集中在 `main.js` 的 `FEATURES` 数组；其余文案在 `index.html` 中直接修改。
- **改配色**：所有颜色集中在 `styles.css` 顶部的 `:root` 与 `[data-theme="dark"]` CSS 变量，`--primary` / `--orange` 即为品牌色。
